ShowCQT Musical Detail — วิธีนำขึ้น GitHub Pages

1. สร้าง repository ใหม่ใน GitHub
2. นำไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้น repository รวมถึงโฟลเดอร์ .github
3. เปิด Settings > Pages
4. ที่หัวข้อ Build and deployment เลือก Source เป็น GitHub Actions
5. เปิดแท็บ Actions และรอ workflow “Deploy GitHub Pages” ทำงานเสร็จ
6. กลับมาที่ Settings > Pages เพื่อเปิดลิงก์เว็บไซต์

การใช้งาน
- เปิดเว็บด้วย Chrome หรือ Edge บนคอมพิวเตอร์
- ลากไฟล์ MP3 หรือ WAV ลงในกรอบ
- รอจนประมวลผลเสร็จ แล้วกดดาวน์โหลดไฟล์ .sv
- วางไฟล์ .sv ไว้โฟลเดอร์เดียวกับ MP3/WAV ต้นฉบับ แล้วเปิด .sv ด้วย Sonic Visualiser

หมายเหตุ
- เพลงถูกประมวลผลในเว็บเบราว์เซอร์บนเครื่อง ไม่ถูกอัปโหลดไปยังเซิร์ฟเวอร์
- ไฟล์ .sv เก็บภาพวิเคราะห์และอ้างอิงเพลงต้นฉบับตามชื่อไฟล์ ไม่ฝังเสียงในตัว
- หาก Sonic Visualiser ถามหาไฟล์เสียง ให้เลือก MP3/WAV ต้นฉบับ
