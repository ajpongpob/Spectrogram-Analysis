# MuSpec Lab v1.0.0

MuSpec Lab เป็นเว็บแอปสำหรับวิเคราะห์และสำรวจรายละเอียดของเสียงดนตรีด้วยภาพ 2D/3D พร้อมเครื่องมือเขียนกำกับและส่งออกภาพ ประมวลผลในเบราว์เซอร์บนเครื่องผู้ใช้ โดยไม่อัปโหลดไฟล์เสียงไปยังเซิร์ฟเวอร์

**เปิดใช้งาน:** https://ajpongpob.github.io/Spectrogram-Analysis/?v=1.0.0

## การเปิดไฟล์และวิเคราะห์เสียง
- เปิดไฟล์ MP3 หรือ WAV ด้วยการเลือกไฟล์หรือลากวาง แสดงความคืบหน้า ยกเลิกการวิเคราะห์ และเปลี่ยนไฟล์ได้
- ถอดรหัสเสียงที่ 44.1 kHz และวิเคราะห์ด้วย ShowCQT จำนวน 960 ช่องความถี่ อัตรา 60 เฟรมต่อวินาที อ้างอิง A4 = 440 Hz
- ลดหน่วยความจำด้วยการกรองเสียงแบบหน้าต่างเลื่อน ไม่เก็บสำเนาเสียงที่กรองแล้วทั้งเพลง และใช้ข้อมูลร่วมกันสำหรับไฟล์โมโน
- ประเมินหน่วยความจำตามความสามารถของเบราว์เซอร์ พร้อมคำแนะนำความยาวคลิปเมื่อไฟล์เกินงบ รองรับไฟล์ไม่เกิน 250 MiB; ระยะเวลาที่รองรับขึ้นกับเครื่องและเบราว์เซอร์

## มุมมอง 2D และ 3D
- สลับระหว่างสเปกโตรแกรม 2D และพื้นผิวเสียง 3D โดยใช้ข้อมูลเสียง ตำแหน่งเล่น และช่วงเวลา/ย่านเสียงร่วมกัน
- เลือกช่วงเวลาและย่านเสียง ซูมเวลา/ระดับเสียงด้วยปุ่มหรือล้อเมาส์ ลากกรอบซูมใน 2D เลื่อนภาพ และคืนมุมมองเต็มเพลง/เต็มย่าน
- 3D รองรับการหมุน มุมก้มเงย ความสูง การเลื่อนและซูมภาพ มองจากด้านบน และคืนมุมกล้อง พร้อมจัดภาพให้พอดีกรอบ
- เปิดเต็มจอได้ทั้ง 2D/3D พร้อมปุ่มออกและ Escape; มีมุมมองขยายสำรองเมื่อเบราว์เซอร์ไม่รองรับ Fullscreen API
- เล่น/หยุดเสียง เลือกตำแหน่งผ่านแถบเวลา หรือคลิกบนกราฟ เปิด/ปิดการเลื่อนภาพตามเสียง และใช้ Space เพื่อเล่น/หยุด

## สเกลระดับสัญญาณและธีมสี
- **CQT:** เหมาะสำหรับดูรายละเอียดของเสียงและโน้ต โดยแสดงความเข้มด้วยสเกลของ ShowCQT
- **dBFS:** เหมาะสำหรับเปรียบเทียบระดับสัญญาณในแต่ละย่านความถี่ โดยใช้สเกลเดซิเบลที่มีค่าอ้างอิงคงที่ ไม่ใช่ระดับเสียงจริงที่วัดด้วยไมโครโฟน (dB SPL)
- สเกลใช้ร่วมกันทั้งสองโหมด: 2D แสดงแถบสีและค่าที่ตำแหน่งเมาส์ ส่วน 3D แสดงระดับผ่านสีและแกนความสูง
- dBFS เลือกช่วง −60, −90 หรือ −120 ถึง 0 dBFS ได้ ค่าอ้างอิงไม่เปลี่ยนตามการซูม
- ธีมสี Aurora, Magma, Inferno, Viridis และ Graphite ซึ่งเป็นภาพขาวดำบนพื้นขาว
- ปรับความสว่าง/ความเข้ม และการเน้นยอดเสียงตามรูปแบบการแสดงผล โดยปิดการปรับ gain/peak ใน dBFS เพื่อรักษาสเกลที่สอบเทียบไว้
- เก็บข้อมูล CQT และสูตรสีเดิมแยกจากข้อมูลระดับ dBFS

## แกน กริด และเสียงอ้างอิง
- เลือกแกนเสียงได้ 4 แบบ: โน้ต + เปียโน, ความถี่ + เปียโน, โน้ต และความถี่ โดยสองแบบหลังไม่มีลิ่มเปียโน
- เลือกตำแหน่งแกนเสียงใน 3D ได้ทางซ้ายหรือขวา ผ่านหมวดแกนและกริด
- เปิด/ปิดกริดโน้ตและกริดเวลา; กริด 3D แสดงซ้อนผ่านพื้นผิวเพื่อให้มองเห็น
- เลือกรูปแบบเวลาเป็นวินาทีหรือนาที:วินาที และแสดงค่าโน้ต/ความถี่ตามช่วงที่ซูม
- คลิกลิ่มเปียโนใน 2D/3D เพื่อฟังเสียงสังเคราะห์คล้ายเปียโนที่ตรงกับคีย์และอ็อกเทฟ ใช้ระบบเสียงเท่ากัน 12 เสียง อ้างอิง A4 = 440 Hz โดยไม่เปลี่ยนตำแหน่งเล่นเพลง

## เขียนกำกับและจัดการวัตถุ
- เขียนกำกับได้ทั้ง 2D/3D โดยใช้ชิ้นงานร่วมกันและยึดตำแหน่งเวลา/ระดับเสียง
- เครื่องมือข้อความ เส้น สี่เหลี่ยม วงรี/วงกลม สามเหลี่ยม ลูกศร ลูกศรสองหัว และไฮไลต์
- กด Shift ขณะวาดวงรีหรือสี่เหลี่ยมเพื่อสร้างวงกลมหรือสี่เหลี่ยมจัตุรัส
- เลือก ลากย้าย ลบ คัดลอก และวางวัตถุ แก้สี ขนาดเส้น ข้อความ และขนาดตัวอักษรของชิ้นงานที่เลือก
- ขนาดเส้น 0.25–48 px ปรับทีละ 0.25 px; ขนาดข้อความ 8–96 px และข้อความหลายบรรทัดได้สูงสุด 240 ตัวอักษร
- มีสีสำเร็จรูป 8 สีและตัวเลือกสีเอง พร้อม Undo/Redo และล้างชิ้นงาน
- รองรับ ⌘/Ctrl+C, V, Z, Shift+Z, Ctrl+Y และ Delete/Backspace โดยไม่รบกวนการแก้ไขข้อความในช่องกรอก
- บันทึกชิ้นงานในเบราว์เซอร์โดยผูกกับไฟล์เสียง เปิดไฟล์เดิมเพื่อเรียกคืนได้; คลิปบอร์ดวัตถุใช้ภายในแท็บแอป
- วัตถุ 3D เก็บจุดอ้างอิงความสูงของระนาบวาด และปรับตำแหน่งบนพื้นผิวเมื่อสลับสเกล CQT/dBFS

## ส่งออกภาพ
- หมวด **ส่งออก PNG** แยกจากหมวดมุมมอง 3D
- 2D: ลากเลือกกรอบภาพ รวมแกนได้ เลือกความละเอียด 2×/3×/4× ดาวน์โหลดหรือคัดลอก PNG เมื่อเบราว์เซอร์อนุญาตคลิปบอร์ด
- 3D: บันทึก PNG ของมุมกล้องปัจจุบัน รวมแกน กริด และชิ้นงานเขียนกำกับ
- ภาพส่งออกรวมชิ้นงานที่มองเห็น; ภาพ 2D ที่เตรียมไว้จะต้องเลือกใหม่เมื่อมุมมองหรือข้อมูลภาพเปลี่ยน

## ส่วนติดต่อและภาษา
- ธีม MuSpec Lab แบบ Minimal White สำหรับเดสก์ท็อป พร้อมแผงเครื่องมือกระชับ
- เครื่องมือที่ใช้บ่อยอยู่ด้านบน เครื่องมือเพิ่มเติมอยู่ในหมวดด้านข้าง เปิดขยายทีละหมวดและคงอยู่จนเลือกหมวดอื่น
- สลับ TH/EN ได้ทันทีโดยไม่วิเคราะห์เสียงใหม่ และจดจำภาษาที่เลือก
- มีคู่มืออ่านภาพ วิธีใช้งาน เกี่ยวกับแอป และข้อความการอ้างอิง MuSpec Lab
- เครื่องมือส่งออก `.sv` รุ่นเดิมยังเข้าถึงได้ที่ `legacy.html`

## สิ่งที่ปรับในรีลีสนี้
- แสดงหมายเลขเวอร์ชัน **v1.0.0** บนหน้าหลัก หน้าวิเคราะห์ และชื่อแท็บ
- เอาประโยค “CQT: ค่าสำหรับแสดงภาพจาก ShowCQT ไม่ใช่ dB” ที่ซ้ำออก รวมถึงข้อความภาษาอังกฤษคู่กัน โดยคงคำอธิบายสองย่อหน้าที่อนุมัติไว้
- กำหนดเวอร์ชันให้หน้าวิเคราะห์และไฟล์ส่วนติดต่อ เพื่อป้องกันการแสดงข้อความเก่าจากแคช

## ขอบเขตการตีความข้อมูล
- dBFS เป็นระดับรายย่านจาก CQT ที่สอบเทียบกับเสียงไซน์ ไม่ใช่ dB SPL, loudness หรือค่าพลังงานรวมแบบ broadband RMS
- เสียงเปียโนอ้างอิงเป็นเสียงสังเคราะห์ ไม่ใช่ตัวอย่างเสียงเปียโนอะคูสติก
- การซูมขยายการแสดงผล ไม่ได้เพิ่มความละเอียดข้อมูลวิเคราะห์; พื้นผิว 3D ใช้ตาข่ายลดจำนวนจุดเพื่อให้แสดงผลได้คล่องตัว
- ชิ้นงานเก็บในเบราว์เซอร์เครื่องนั้น การล้างข้อมูลเว็บไซต์อาจลบชิ้นงานที่บันทึกไว้
