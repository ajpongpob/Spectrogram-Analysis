# MuSpec Lab v1.0.1 — 1D Frequency Slice

เพิ่มโหมด **1D** ในโปรเจคหลัก โดยเรียงปุ่ม **1D / 2D / 3D** และใช้ผลวิเคราะห์ไฟล์เสียงชุดเดียวกัน สลับมุมมองได้ทันทีโดยไม่วิเคราะห์ซ้ำ

- ชี้ตำแหน่งบนกราฟ 2D หรือพื้นผิว 3D แล้วสลับมา 1D เพื่อดูความถี่ ณ เวลานั้น การเข้า 1D จะหยุด Playback เพื่อให้ตรวจภาพตัดได้คงที่
- แกนนอนแสดงความถี่แบบ Logarithmic หรือ Linear; แกนตั้งเลือก CQT หรือ dBFS ร่วมกับ 2D/3D
- ใช้ชุดสี Aurora, Magma, Inferno, Viridis และ Graphite ตามการตั้งค่าร่วมของโปรแกรม
- เลื่อนทีละเฟรม ระบุเวลา อ่านความถี่/ระดับสัญญาณใต้เมาส์ และแสดงยอดความถี่พร้อมโน้ตใกล้เคียง
- เล่นเสียงพร้อมกราฟ 1D ที่เปลี่ยนตามเวลา ขยายเต็มจอ และส่งออก PNG หรือ CSV ครบ 960 ช่องความถี่
- รองรับ TH/EN และเครื่องมือด้านข้างที่ปรับตามมุมมอง; เครื่องมือเขียนกำกับเดิมยังใช้ใน 2D/3D
- อัปเดตชื่อเวอร์ชันและตัวอย่างอ้างอิงเป็น 1.0.1 โดยคงเงื่อนไขสิทธิ์และเครดิตเดิม

การเลือกเวลาใช้เฟรมที่ใกล้ที่สุดจากข้อมูล 60 เฟรม/วินาที และคำนวณจากหน้าต่างเสียงรอบเวลานั้น ไม่ใช่ตัวอย่างเสียงเดียว จุดยอดอาจเป็นฮาร์มอนิกหรือเสียงรบกวน ไม่ใช่ผลแยกโน้ตอัตโนมัติ dBFS เป็นค่าระดับดิจิทัลเทียบเสียงไซน์เต็มสเกล ไม่ใช่ dB SPL ในห้อง

ShowCQT, ข้อมูลวิเคราะห์ CQT, การสอบเทียบ dBFS และสูตรชุดสีเดิมไม่ได้เปลี่ยน

## Validation

- Built production assets successfully.
- Browser checks with MP3 and a generated WAV containing 220/440/880 Hz sections: nearest-time transitions from 2D and 3D to 1D; CQT/dBFS, palette selection, frame stepping, frequency-axis selection, language switching, fullscreen and layouts at 1280 × 720 and 1440 × 900. PNG download verified; CSV serialization checked across all 960 bins.
- 1D data tests: nearest-frame rounding and boundaries, three registers, level conversion, silence and immutable source matrices.
- 3D math: 4,314 inverse projections plus perspective picking, depth selection and cropping.
- dBFS calibration: 15,360 sine-level cases, maximum error 0.174 dB (rounded upward).
- Existing reference-color and gain tests passed.
